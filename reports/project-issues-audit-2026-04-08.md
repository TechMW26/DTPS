### B. Build passes, but functional warnings indicate broken/partial integrations
- Command: `npm run build`
- Result: **Build success**, but warnings present
- Full output: `reports/build-report-2026-04-08.txt`

#### B1) Appointment config model is broken in import registry path
- Symptom in build logs: `[ModelRegistry] Invalid model: AppointmentConfig. Model or schema is undefined.`
- Where it breaks:
  - `src/lib/import/modelRegistry.ts` imports default `AppointmentConfig`
  - `src/lib/db/models/AppointmentConfig.ts` default export is an object of models, not a single Mongoose model
- Impact: import-model registry cannot register `AppointmentConfig` and related import functionality is partially broken.

#### B2) Zoom integration not configured
- Symptom in build logs: `Zoom API credentials not configured`
- Where it breaks: `src/lib/services/zoom.ts`
- Impact: Zoom meeting-related flows will be unavailable/fallback where this service is required.

#### B3) Duplicate Mongoose index declarations (runtime overhead + noisy logs)
- Repeated warnings for duplicate indexes on: `email`, `phone`, `days`, `key`, `expiresAt`
- Likely break points:
  - `src/lib/db/models/User.ts` (`email`/`phone`)
  - `src/lib/db/models/DurationPreset.ts` (`days`)
  - `src/lib/db/models/Permission.ts` (`key`)
  - `src/lib/db/models/OTPRecord.ts` (`expiresAt`)
- Impact: not a compile failure, but noisy startup/build logs and potential schema maintenance risk.

#### B4) Next warning on custom cache-control headers
- Symptom: `Custom Cache-Control headers detected for /_next/static/:path*`
- Impact: may affect expected Next.js behavior in development/runtime edge-cases.
